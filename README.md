# Twitter Sentiment Analyzer — GUI

## نصب و اجرا

```bash
pip install -r requirements.txt
streamlit run app.py
```

باید ساختار پوشه‌ها دقیقاً همینطوری کنار هم باشند (تغییرشون نده):

```
sentiment_app/
├── app.py
├── requirements.txt
├── model/
│   └── model_scratch_sentiment.keras
└── data/
    └── twitter_training_clean_binary.csv
```

## چرا فایل CSV آموزش هم لازم است؟

لایه‌ی `TextVectorization` (که متن رو به عدد تبدیل می‌کنه) توی نوت‌بوک
هیچ‌وقت جداگانه ذخیره نشده بود — فقط خود مدل با `.save()` ذخیره شده.
برای اینکه ورودی‌های جدید دقیقاً همون‌جوری توکنایز بشن که موقع آموزش
می‌شدن، اپ موقع اجرا اول با همون split (`test_size=0.1, random_state=42`)
و همون تنظیمات (`max_tokens=20000`, `output_sequence_length=40`) روی
همون فایل CSV، واژگان (vocabulary) رو از نو می‌سازه — و بعد فقط وزن‌های
آموزش‌دیده‌ی مدل رو روی معماری بازسازی‌شده لود می‌کنه. این کار چند ثانیه
اول اجرا طول می‌کشه ولی بعدش cache می‌شه (`st.cache_resource`).

اگه فایل CSV رو عوض کنی یا ترتیب ردیف‌هاش فرق کنه، واژگان بازسازی‌شده
با وزن‌های مدل هم‌خوانی نخواهد داشت و نتایج غلط می‌شن.

## قابلیت‌ها

- تحلیل تکی یک توییت با نوار اطمینان (confidence)
- سه نمونه‌ی آماده برای تست سریع
- تحلیل دسته‌ای: آپلود یک CSV با ستون `text`، خروجی با ستون‌های
  `sentiment` و `confidence`، قابل دانلود
- نوار کناری با اطلاعات معماری مدل
